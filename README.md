# VPN Server on GitHub Actions (Xray + Tailscale Funnel)

این ریپو یک سرور VPN (پروتکل VLESS با ترنسپورت WS و XHTTP) روی رانرهای گیت‌هاب اکشنز اجرا می‌کند.

## چطور کار می‌کند؟

1. Xray با دو اینباند محلی بالا می‌آید: WS روی پورت 8081 و XHTTP روی پورت 8082
2. رانر با Tailscale به شبکه‌ی خصوصی وصل می‌شود (کلید با OAuth هر بار تازه ساخته می‌شود، پس هرگز منقضی نمی‌شود)
3. با Tailscale Funnel سرویس به اینترنت عمومی منتشر می‌شود:
   - پورت 443 → WS (`/ws`)
   - پورت 8443 → XHTTP (`/`)
4. تست E2E از خود اینترنت عمومی انجام می‌شود؛ اگر پاس شد، کانفیگ‌های نهایی به تلگرام ارسال می‌شوند
5. کرون هر ۶ ساعت یک ران جدید می‌سازد → سرور همیشه آنلاین است و کانفیگ‌ها هر ۶ ساعت تازه می‌شوند

## Secrets مورد نیاز

| Secret | توضیح |
|---|---|
| `TS_OAUTH_CLIENT_ID` | کلاینت OAuth تیل‌اسکیل (برای ساخت کلید اتصال خودکار) |
| `TS_OAUTH_CLIENT_SECRET` | سکرت همان کلاینت |
| `XRAY_UUID` | UUID کاربر VLESS |
| `TG_BOT_TOKEN` | توکن بات تلگرام برای ارسال کانفیگ |
| `TG_CHAT_ID` | چت آیدی مقصد تلگرام |

## اجرای دستی

اکشنز تب → **VPN Server (Xray + Tailscale Funnel)** → Run workflow

کانفیگ‌های `vless://` بعد از هر ران به تلگرام ارسال می‌شوند.
